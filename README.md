# Açaí Raiz

Site da [Açaí Raiz](https://www.acairaiz.com), produtora de polpa de açaí e
cafés do grão de açaí em Sergipe. Em três idiomas: português (padrão), inglês e
espanhol.

Next 16 · React 19 · TypeScript · Tailwind v4 · shadcn/ui · next-intl

```bash
npm install
npm run dev      # http://localhost:3000
```

Rotas: `/` (pt-BR), `/en`, `/es`.

Convenções do projeto, decisões de i18n e armadilhas conhecidas estão em
[CLAUDE.md](CLAUDE.md).
